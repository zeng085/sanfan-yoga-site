## 四、P1：口径不一致（需确认后统一）

### 4.1 MOQ 三种说法

| 位置 | MOQ |
|---|---|
| 站点 ym1–ym4 / fr1 / fr2 / fr4 / pr4 | **100 / 500 pcs** |
| 站点 ym5–ym7 | On request |
| **报价表** | oval yoga mat 定制 logo **20 pcs**；pilate ring 定制 logo **3000 pcs** |

→ 20 pcs 与 100 pcs 差 5 倍。哪个是对外口径？**这是询盘转化的第一道门槛，写错直接影响成单率。**

### 4.2 认证口径（合规风险最高）

- 站点 27 页统一写：`REACH, CA Prop 65, 6P/7P, ISO 9001, BSCI`
- 最新资料里：
  - 瑜伽目录 P56 认证页 = **9 张 CE 证书 + 12 张专利证书**（专利是外观/实用新型，不是质量认证）
  - 报价表 = **0 条认证信息**
  - 两份目录均**未见 REACH / BSCI / ISO 9001 证书**

→ 站上写的四项认证在新资料里找不到依据。欧美买家会索要证书编号，**报不出编号比不写更伤信任**。建议回厂里要一份"认证清单 + 证书编号 + 有效期"。

### 4.3 报价表缺列，站点无从对齐

价格表**没有**：MOQ 列、认证列、梯队价、EXW 价、交货期、计价单位。

**计价单位缺失是最危险的**——同一列价格里混着三种计价方式：

| 计价方式 | 产品 |
|---|---|
| /pc（单只） | 瑜伽垫、瑜伽砖、Bosu Ball、瑜伽柱 |
| /pair（一对） | 硅胶哑铃（$9.74 是**一对**的价）、硅胶手环 |
| /set（一套） | 弹力带五色套装、拉力绳套装 |

→ 上站时若统一按"件"理解，报给客户的价格会差 2–5 倍。

## 八、机会点：价格与 SKU 的两种用法

### 8.1 SKU 编号改成工厂编号（建议做）
站点现在用 `ym1-ym8 / fr1-5 / pr1-5` 内部编号，客户拿工厂目录来问 `S1A21` 时对不上。
建议产品页 URL 与页面标题统一采用工厂 SKU（`products/s1a21-pu-rubber-yoga-mat.html`），并在页内标注 S1A21。**好处**：客户询盘直接说 SKU，报价、打样、跟单全链路不会错款。

### 8.2 价格上站（需你拍板）
现在 27 页全部写 `MOQ: On request`，一个价格都没有。而报价表已经给了 FOB 厦门价，可考虑三种做法：

| 方案 | 做法 | 适合 |
|---|---|---|
| A 完全不显示 | 维持现状 | 传统工厂思维，但流失"先看价再联系"的客户 |
| B 显示起步价 | `From $5.89 / pc (FOB Xiamen, MOQ 500)` | **推荐**：过滤掉量太小的询盘，同时是 AI 最爱引用的数字型内容 |
| C 只对询盘给 | 表单提交后自动回价目表 PDF | 需要自动化配套 |

**B 的额外价值（GEO）**：AI 搜索里 "how much does a TPE yoga mat cost from China" 这类问法很常见，目前回答都引用第三方平台报价。你手上有真实 FOB 价，**这是极少有工厂愿意公开、但正是 AI 会引用的内容**。

## 十一、图片能否更新 —— 已实测验证：能

（本节为 2026-09-10 晚追加，回答「图片是否能更新」）

### 11.1 三条通路，逐一实测

| 通路 | 实测结果 | 可用性 |
|---|---|---|
| ima 知识库 API | `fetch_media_content` 只返回 OCR 文本；官方 9 个接口无 download，图片条目无 URL 字段 | ❌ 拿不到图 |
| **瑜伽目录 PDF** | 57 页整页图，原始 **2481×3367 / 300–900KB**；自动裁切出 **204 张产品图（约 700×520）** | ✅ **可提，质量最好** |
| **健身目录 PDF** | 内含 **197 张独立产品图**（JPEG/JP2，中位 590×510 / 31KB）+ 29 张整页图 | ✅ 可提，分辨率略低 |

**合计可提取素材约 400 张**，当前站点全部图片只有 67 张（其中产品图 27 张）。

### 11.2 质量对比（关键结论）

| | 站点现有产品图 | PDF 裁切新图 |
|---|---|---|
| 分辨率 | 480×480 / 750×750 / 800×800 | ~700×520（瑜伽）/ ~590×510（健身） |
| 体积 | 5–68KB（已 WebP 压缩） | 提取后 300–900KB，压缩后预计 40–80KB |
| 水印 | 无 | **无**（实测裁切样图干净） |
| 参数卡 | 无 | **自带**（材质/尺寸/克重/装箱全在图旁） |

实测裁切样例（瑜伽目录 P30，S1A11 单层 TPE）：3 张一组，696×518，白底、纹理清晰、可直接上站。

### 11.3 三种用法，价值递增

| 用法 | 说明 | 工作量 |
|---|---|---|
| ① 换主图 | 27 个产品页主图替换为目录提图 | 低 |
| ② 补图集 | 每页从 1 张主图 → 主图 + 多角度 + 细节（目录每产品通常 3 张起） | 中 |
| ③ **详情长图** | 57 张整页图（2481×3367）本身即完整产品详情页 —— 含规格表 + 多角度图 + 装箱数据，直接挂产品页做「详情」区块 | **最高** |

用法 ③ 是把一个「1 张图 + 3 条泛泛卖点」的产品页，一次性变成「完整规格表 + 多角度实拍 + 装箱数据」的专业页，是转化率提升最直接的一步。

### 11.4 上线前必须先做的三件事（否则会把错图配错页）

1. **建 SKU 映射表**：目录用工厂编号（S1A11/S1A12/S1A21…），站点用 ym1–ym8 / fi1–fr5。**不建立映射就不知道哪张图属于哪页**，这是硬前置。
2. **先修参数再上图**：目录图旁印着尺寸参数，站点参数有 7 处冲突（见第三节）。图上了参数没改，等于把矛盾印在客户脸上。
3. **图片规范化处理**：目录图底是浅灰（非纯白），需统一裁白边/补白底；转 WebP q75、`<150KB`、带 `width/height`。

### 11.5 风险与边界

- 自动裁切已实测有效（白边检测 + 彩色判据），但**证书页/封面页会误命中**，需人工抽检排除。
- 健身目录的 197 张独立图需与现有 fi1–fr5 页面逐一比对，避免引入重复。
- 目录图分辨率（700×520）**适合产品页，不适合做首页 banner**。
- 瑜伽目录无文本层，工厂 SKU 需 OCR 或人工摘录（建议用 macOS 本地 OCR，不走云服务）。

### 11.6 建议动作

**这一步不需要你提供任何新素材**，从现有两份 PDF 即可产出全部图片资产。建议顺序：

```
建 SKU 映射表（需你或厂里按图认货一次）
   ↓
修 7 处参数冲突（阶段 1）
   ↓
批量提图 → 规范化 → 上站
   ↓
27 页产品页 + 8 个新页一次性换装
```
