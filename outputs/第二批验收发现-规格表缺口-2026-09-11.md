## 二、证据链：英文站这些页真的没内容

三处交叉验证，全部指向同一结论：

| 检查项 | `foam-roller`（正常） | `eva-foam-roller`（薄） | `yoga-ball`（薄） |
|---|---|---|---|
| WP REST `content.rendered` 长度 | **1068** | **0** | **0** |
| WP REST `excerpt.rendered` 长度 | **238** | **0** | **0** |
| 前端页面 `<table>` / `<tr>` 数 | 1 / **11** | **0 / 0** | **0 / 0** |
| 页面出现 `Material`/`Thickness`/`MOQ` 词频 | 有 | **0 / 0 / 0** | **0 / 0 / 0** |

- 还特别排查了「数据藏在 WooCommerce 变体属性里」的可能 —— 这些页 `<table>` 数为 0，连变体下拉表都没有。
- 页面 HTML 里唯一出现的 "Specification" 字样来自 Yoast SEO 的 `PropertyValueSpecification` schema，**不是规格表**。

**结论：英文站这 19 个产品页是"空壳页"——只有标题、图片、价格、加购按钮，没有规格、没有描述。**
