# ima 产品图库诊断与整改建议（v2 修订版）

扫描对象：ima 个人知识库「sanfan的知识库」→ 产品图片
对照基准：fjsanfan.com 站点现状（27 个产品页、assets/img 实际在用图）
修订时间：2026-09-09（根据用户澄清「产品透明白底图 = 全产品白底图汇总」修正 v1 判断）

> 本报告只做诊断与方案，**未改动任何文件**。

## 〇、v1 的一处误判，先更正

v1 我把「产品透明白底图」和「瑜伽垫系列/按摩系列…」判为**双轨重复**。你澄清后更正：

| 分支 | 真实定位 | 数量 |
|---|---|---|
| **产品透明白底图** | **全品类白底 / 透明主图母库**（所有产品的主图汇总） | **183 张**（白底 134 + 透明 49） |
| 瑜伽垫系列 / 按摩系列 / 体考系列 / 瑜伽砖系列 | 按 SKU 分的**详情图 / 场景图**源 | 约 80–100 张 |

所以这不是重复，是「主图母库 + 详情图源」的合理分工。**v1 的结构批评只对一半**：真正该改的不是拆掉这条线，而是**目录层级冗余**（`产品透明白底图/产品白底图/瑜伽垫/` 三层前缀，前两层可合并成一层）。

## 一、新发现：每个产品页真正属于自己的图，只有 1 张

这条比 v1 的所有问题都严重。

27 个产品页，每页有 7–8 个 `<img>` 标签、5 张唯一图。但拆开看：

```
ym5.html（PU/橡胶高端垫）的 5 张图：
  1. pu-rubber-mat-1   ← 它自己
  2. tpe-mat-1         ← 相关产品
  3. tpe-mat-2         ← 相关产品
  4. tpe-mat-3         ← 相关产品
  5. tpe-foldable-1    ← 相关产品
```

**每一页都是这个结构**——第 1 张是自己的主图，后 4 张是同品类其他产品（相关推荐位）。

| 指标 | 数值 |
|---|---|
| 每个产品页属于自己的图 | **1 张** |
| 站点唯一产品图总数 | **27 张** |
| 白底 / 透明主图母库 | **183 张** |
| **母库上站率** | **约 15%**（156 张没用上） |

站上现在的状态是：**一个产品 = 一张白底图**。没有场景图、没有细节纹理、没有厚度对比、没有尺寸图。B2B 买家看不到细节就不敢下单——这是转化率上的硬伤，不是美观问题。

## 二、命名无语义的代价（现在就卡住了，不是理论问题）

我试着把站点在售的瑜伽垫 SKU 对应到你白底母库里的图，结果：

| 站点产品页 | 库中候选 | 能否确认 |
|---|---|---|
| ym3 双人加宽 TPE 垫 | `双人瑜伽垫.jpg` | ✅ 能对应 |
| ym5 PU / 橡胶高端垫 | `土豪垫凌新.jpg`、`国标土豪垫.jpg` | ✅ 能对应（土豪垫 = PU+橡胶） |
| ym1 TPE 瑜伽垫 | `TPE双色新款`、`TPE经济垫单色`、`TPE旧款单色`、`单色实用垫`… | ⚠️ 6 张候选，分不清哪张是在售款 |
| ym6 磨砂 PU 瑜伽垫 | ？ | ❌ 库里没有任何一张名字带「磨砂」或「PU」 |
| ym7 迷彩 PU 瑜伽垫 | ？ | ❌ 只有 `TPE迷彩垫`，材质对不上 |
| ym2 加宽 TPE 垫 | ？ | ❌ 没有「加宽」标识 |
| ym4 折叠 TPE 垫 | ？ | ❌ 折叠垫有 3 张，全是「麂皮绒/橡胶」前缀，没有纯 TPE 折叠 |

**结论：命名问题不是"以后不好找"，是"现在就无法安全上站"。** 我只能靠猜，猜错就是把错误产品的图挂到客户面前。

## 四、修订后的整改路线

原路线 A→B→C→D 顺序不变，但 **A 阶段的内容变了**：既然白底母库是全品类汇总，关键动作就不是"大重构目录"，而是**先把 183 张筛成「在售 SKU 对照表」**。

### 阶段 0：建 SKU ↔ 主图对照表（半天，最高性价比）

这一步**必须人工确认**，因为需要"按图认货"——你或厂里同事扫一眼就知道哪张是磨砂 PU。我负责出表，你负责填确认列。

表格结构：

| 站点产品页 | 产品名 | 库中候选文件名 | 是否采用 | 缺什么图 |
|---|---|---|---|---|
| ym1 | TPE 瑜伽垫 | TPE双色新款.jpg / TPE经济垫单色.jpg … | ○ | 场景、细节、厚度 |
| ym6 | 磨砂 PU 瑜伽垫 | （待补） | ○ | 全部缺 |
| … | | | | |

顺带产出三张清单：
1. **在售主图清单**（约 27–50 张）→ 规范命名 + 转 WebP 上站
2. **旧款/废图清单**（含「旧版」「副本」「详情灰」）→ 归入 `_归档/`，不删
3. **缺图清单** → 需要补拍的产品（预计 5–8 个 SKU）

### 阶段 A：定标准（半天）

**A1 命名规范**
```
{品类}-{材质}-{规格}-{颜色}-{角度}-{序号}.webp
例：yoga-mat-tpe-6mm-black-main-01.webp
    yoga-mat-cork-rubber-5mm-natural-detail-02.webp
```
角度取值：`main` / `front` / `scene` / `detail` / `thickness` / `rolled` / `pkg` / `factory`

**A2 一产品五图标准**（每个在售 SKU）
1. 白底主图 ← **母库已有，现成**
2. 场景图（人在用）← 需从 SKU 支详情图里找或补拍
3. 细节图（表面纹理 / 防滑层特写）
4. **厚度对比图（带硬币或尺子做参照）** ← B2B 最关心、现在完全空白
5. 卷起 / 尺寸图

**A3 目录压到三级**（不是拆掉，是压扁）
```
产品图片/
├── 白底主图/            ← 原「产品透明白底图/产品白底图」合并
│   ├── 瑜伽垫/
│   └── 按摩系列/
├── 详情场景图/          ← 原「瑜伽垫系列/按摩系列…」
│   └── TPE双色垫/
└── _归档/
```
用途（白底/透明/场景/细节/尺寸）交给 **ima tags** 承担。

### 阶段 B：批量处理（1–2 天）
1. MD5 去重（11.7MB 那张就存了两份，预计能清 20–30%）
2. 批量重命名（去「副本」、序列号转语义、补英文）
3. 转 WebP q75、最长边 1600px、目标 <150KB
4. 索引表落库（存回 ima，以后 AI 找图直接查表）

### 阶段 C：上站（1 天）
1. 27 个产品页各补齐 5 图（**先做 8 个瑜伽垫页**，这是主业）
2. 重写 991 处通用 alt：`{材质} {产品} {规格} — {卖点/用途}`
3. bump 版本号、提交上线

### 阶段 D：补两类空白图
1. **厚度 / 密度对比图** —— GEO 文案写了"比确认样轻 200g 即降配""±3mm 公差"，却没有一张论据图
2. **检测报告证据图** —— 库里有 RoHS / CA65 / CE 的 PDF（QLAB-2508TF0367 等），转 PNG 即可用于文章举证

## 五、需要你拍板的三件事

1. **水印**：现有图带 SANFAN 水印。做 OEM 客户案例时对方不希望看到你的 logo——要不要出「无水印版 + 客户 logo 版」两套？
2. **起手范围**：建议先做 **8 个瑜伽垫页**（ym1–ym8，主业且素材最全），你确认？
3. **旧图**：带「副本」「旧版」的归入 `_归档/` 保留，还是直接清掉？

## 六、一句话总结

> 不缺素材（183 张白底主图母库 + 约 100 张详情图），缺的是**对照关系**和**命名**。现在站上一个产品只有 1 张图，而库里平均每个产品有 6–7 张。把「哪个产品在库里是哪张图」这张对照表建起来，剩下的都是机械劳动。
