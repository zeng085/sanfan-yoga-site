### 三条设计决定（值得复用）

1. **产品页 FAQ 必须页页不同**：1029 页若用同一段模板文案，等于自造重复内容。
   做法是把该页规格表的真实值（MOQ / 尺寸 / 厚度 / 认证）嵌进答案句子。
2. **JSON-LD 不改进原块**：在原 `@graph` 块**之后**追加独立 `<script>`，
   避免整块 diff；WebPage 用 `#webpage` @id，FAQPage 用 `isPartOf` 引它。
3. **标记 + 替换式注入**：可见块 `<!-- plfaq:v1 -->` / `<!-- pfaq:v1 -->`，
   JSON-LD 块 `-ld:v1`；重跑先 `strip_blocks()` 摘旧块 → 幂等可反复跑。

### 五个新坑（已写进长期笔记）

1. ⭐ **DeepL 完整保留全大写下划线占位符**（`XXFAMILYXX` / `XXMODELSXX` / `XXNAMEXX`），
   但**只在同位语/主语位**成立；放进介词短语会被德语语法改写 → 占位符别塞进介词结构。
2. ⭐ **JSON-LD 答案取错元组下标**：`qa_ld = [(q,a) for q,a,_,_ in pairs]` 抓到了中文问句。
   教训：解包多元组时**显式写索引**，并加断言 `a != q and len(a) >= 80`。
   —— 是浏览器验收脚本报"有答案过短"才发现的，**静态检查看不出来**。
3. ⭐ **`esc()` 之前必须先 `html.unescape`**：规格表原文是 `Colors &amp; Print`，
   直接转义会产出 `&amp;amp;`。凡是从既有 HTML 里抠文本再输出的，都要先 unescape。
4. ⭐ **中文模板里英文专名后不要无脑加空格**：中文名后加空格会多一个空
   → 写 `nz()` 判末字符是否 CJK 再决定。
5. ⭐ **替换式注入的空白漂移会让"幂等"永远失败**：每次重插都多吃 2 个空格
   → `strip_blocks()` 要顺手归一化首尾空白（`\n\n  ` / `\n`），不能只删块。
