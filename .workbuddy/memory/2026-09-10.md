## 图片能否更新 —— 实测验证（同日晚）

- **结论：能更新，且无需新增拍摄。** 素材来自用户已提供的两份 PDF，合计约 400 张。
- **瑜伽目录 PDF**：57 页，每页嵌**一张整页图**（2481×3367，300–900KB jpeg），无文本层。用「白边检测 + 彩色判据」自动裁切得 **204 块产品图（约 700×520）**，实测样本（p30 S1A11）无水印、白底、纹理清晰，**优于站点现有 480×480 主图**。整页图本身可直接当**详情长图**用（含规格表+多角度图+装箱数据）。
- **健身目录 PDF**：内嵌 **197 张独立产品图**（154 张 jpx + jpeg，中位 590×510 / 31KB）+ 29 张整页。
- **ima API 仍不可用**（官方 9 接口无 download，图片条目无 URL 字段）——已在报告中固化结论。
- **技术要点（可复用）**：
  - `doc.extract_image(xref)` 对 jpx/jp2 返回的字节存成 .jpg 读不了 → 必须 `fitz.Pixmap(doc, xref)` 后 `pm.save(png)`；`pm.n>4` 时先 `fitz.Pixmap(fitz.csRGB, pm)` 转色。
  - 整页图裁块算法：非白掩码 `a.min(axis=2)<243` → 行投影找内容带（内容像素<1% 视为空白）→ 带内列投影切块 → 相邻段合并（间隔<40）→ 过滤 `w>=250 且 h>=180` → **彩色判据 `(max-min)>30` 占比 >3%** 排除表格/证书页。
  - 瑜伽目录无文本层，工厂 SKU（S1A11 式）需 OCR 或人工摘录；建议 macOS 本地 OCR（Vision），不走云。
