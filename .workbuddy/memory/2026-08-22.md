## 移动端英文界面缩放后布局视口不回缩修复
- 用户反馈：移动端英文界面缩放/缩小后不会自动恢复到移动宽度，中文界面正常。
- 诊断：用 Playwright 全量扫描 index/products/about/contact/product（360~1024px × 中/英）确认——全站两种语言、所有宽度均**无横向溢出**（scrollW==视口宽度），导航临界带(641-980)也无溢出。排除静态 CSS 溢出 / min-content 长单词 / 导航宽度问题。
- 根因判定：iOS Safari 已知行为——英文文案更长，捏合放大后缩回时布局视口被撑宽且不再自动恢复成设备宽度；且 iOS 会在缩放/旋转时自动放大字号(text-size-adjust)进一步破坏"回到移动尺寸"。
- 修复（styles.css 全局，不影响现有视觉与中文侧）：
  - `html` 加 `-webkit-text-size-adjust:100%; text-size-adjust:100%; overflow-x:clip; max-width:100%`（锁定布局视口=设备宽度，iOS 无法卡在宽版；clip 不创建滚动容器故不影响 sticky 头部）。
  - `body` 加 `overflow-x:clip; overflow-wrap:break-word`。
  - `.contact-line` 与 `.field input/select/textarea` 加 `overflow-wrap:anywhere`（邮箱/地址/URL 长串可断行）。
  - 给 `img,table,iframe,video` 补 `max-width:100%` 兜底。
- 验证：复扫全宽度 0 溢出、无回归；390px 中/英均 scrollW==innerWidth==390、汉堡菜单正常（已截图 outputs/mobile-zh.png / mobile-en.png）。
- 部署：git commit(00db24d) 推送 main，Vercel 自动部署；WebFetch 确认线上 CSS 已含上述规则。
